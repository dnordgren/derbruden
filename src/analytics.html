How this is measured

No third-party trackers, beacons, or ad scripts run on DerBruden.com. Traffic comes strictly from CloudFront standard access logs (gzipped NDJSON in a private 90-day S3 bucket), summarized daily into aggregate-only JSON. No IP addresses, cookies, or raw User-Agents are ever published or committed to git.

A lightweight first-party cookie (db_cid) lets the log summary stitch a returning visitor across Wi-Fi and cellular IP changes. A visitor's very first request arrives before the cookie exists; if that same address later carries a db_cid, it is deduplicated so it isn't counted twice. Browsers that block JavaScript or cookies still count as IP-only visitors.

All-time history: raw logs expire from S3 after 90 days. Each daily sync merges completed days into a compact all-time daily rollup (date, page views, human/bot requests, daily visitors, and bytes) so multi-season traffic trends persist without keeping raw logs.

Locations: derived from CloudFront's x-edge-location POP code (e.g., SEA → Seattle, ORD → Chicago, FRA → Frankfurt). This reflects the nearest AWS edge POP rather than exact visitor GeoIP.
